## 📊 BI-аналитика: Дашборд «Анализ продаж» (Power BI)

Интерактивный отчет для мониторинга ключевых коммерческих показателей, маржинальности товарных категорий и эффективности менеджеров.
📁 **Исходный файл проекта:** [Analytics_Dashboard.pbix](Analytics_Dashboard.pbix)

* **Ключевые метрики (KPI):** расчет общей выручки, чистой прибыли, себестоимости, маржинальности (Profit Margin %), среднего чека (AOV) и количества крупных заказов на языке DAX (`CALCULATE`, `FILTER`, `DIVIDE`, `DISTINCTCOUNT`).
* **Категорийный анализ:** матрица рентабельности по товарным группам (Электроника, Офис, Бумага, Канцелярия) с динамическим определением статуса маржи («Высокая», «Средняя», «Низкая»).
* **Интерактивность:** кросс-фильтрация визуальных элементов по менеджерам, категориям и временным периодам (2025–2026 гг.).
