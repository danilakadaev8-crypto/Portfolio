# Портфолио: Бизнес-аналитик / BI-аналитик

Привет! Меня зовут Данила, и это репозиторий с моими практическими проектами. Здесь я демонстрирую навыки работы с данными, визуализации и моделирования бизнес-процессов, необходимые для решения коммерческих задач.

## 📊 1. BI-аналитика (Power BI)
**Дашборд «Анализ продаж»**  
Многостраничный интерактивный отчет для мониторинга коммерческих показателей в ритейле.
* **Навыки:** DAX (CALCULATE, FILTER, DIVIDE, TOPN), Time Intelligence, Data Modeling, настройка кросс-фильтрации.
* **Файл проекта:** [Sales_Analytics_Dashboard.pbix](Sales_Analytics_Dashboard.pbix)

## 🔄 2. Моделирование бизнес-процессов (BPMN 2.0)
**Процесс:** Оптимизация доставки и распределения заказов (на примере e-commerce / foodtech).  
Модель TO-BE с внедрением автоматической балансировки нагрузки между филиалами и авто-назначением курьеров.
* **Навыки:** нотация BPMN 2.0, сбор и формализация требований, анализ узких мест (bottlenecks), проектирование архитектуры процесса.

![Схема бизнес-процесса](bpmn_process.jpg)

## 🗄️ 3. SQL: Работа с базами данных
Скрипты для аналитики и выгрузки метрик (PostgreSQL).
* `01_success_rate.sql` — расчет конверсии и доли успешных заказов.
* `02_median_order_value.sql` — вычисление медианного чека с использованием CTE и оконных функций.
* `03_market_basket.sql` — SQL-запросы для анализа совместных покупок.

## 🐍 4. Python: Алгоритмы и предобработка данных
Скрипты для очистки данных и нормализации структур без использования сторонних библиотек.
* `python_algorithms.py` — функции для валидации форматов (телефонные номера, синтаксис скобок), алгоритмы слияния отсортированных списков (аналог MERGE) и нормализация строковых регистров для БД.
